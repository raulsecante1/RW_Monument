# RW_Monument

## What it is?

MPH(monument to the pawns' heroes) is a Gameplay mod for RimWorld, it adds a new misc type building for game *Rimworld*, which has the functionality of burying multiple bodies

## Project hierarchy

```
project-root/
├── About                                    # contains a single .xml description file, is mandatory
│   └── About.xml                            # 
├── Assemblies                               # 
│   └── MPH.dll                              # contains the mod's dll file
├── Defs                                     #
│   └── ThingDefs/                           #
│       └── MPH_Things.xml                   # defines the MPH's properties
├── Languages/                               # localization files
│   └── ...                                  #
├── Source/                                  # contains the c sharp logic files
└── Textures/                                # textures
│   └── ...                                  #
```

## Compatibility

- RimWorld 1.7
- No known conflicts with other mods.
